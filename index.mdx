json-inference is a TypeScript/JavaScript library that unifies structured output across 12 LLM providers — OpenAI, Claude, DeepSeek, Grok, Mistral, Perplexity, Cohere, Alibaba, Hugging Face, Ollama, GLM-4, and Groq — behind a single `generateObject()` call. Pass a JSON schema, get back a fully typed object. No per-provider SDK wiring, no manual JSON parsing, no fragile prompting.

## Why json-inference?

Many LLM providers support tool calling but not `response_format` / structured outputs. Passing a JSON schema returns free-form text, malformed JSON, or a refusal. json-inference solves this by turning **tool calling into structured output**: your JSON schema becomes a `provide_answer` tool definition, the model is forced to call it via `tool_choice`, and the arguments are extracted, repaired with `jsonrepair`, validated, and retried up to 5 times on failure.

For providers that natively support `response_format` (OpenAI, Grok, Perplexity, Cohere, GLM-4), the library uses it directly. Same API, same schema, same result.

## Quick Example

```typescript
import { generateObject, InferenceName } from 'json-inference';

const result = await generateObject(
  InferenceName.GPT5Inference,
  {
    format: {
      type: "object",
      required: ["sentiment", "confidence"],
      properties: {
        sentiment: { type: "string", description: "positive, negative, or neutral" },
        confidence: { type: "number", description: "Confidence score 0-1" },
      },
    },
    messages: [
      { role: "user", content: "Analyze sentiment: 'This product is amazing!'" },
    ],
  },
  "gpt-4o",
  process.env.OPENAI_API_KEY,
);

// TypeScript infers: result.sentiment → string, result.confidence → number
console.log(result.sentiment, result.confidence);
```

## Getting Started

<Steps>
  <Step title="Install the package">
    Install `json-inference` along with its three required peer dependencies.

    ```bash
    npm install json-inference openai ollama groq-sdk
    ```
  </Step>
  <Step title="Choose a provider">
    Pick an `InferenceName` enum value for the LLM provider you want to use. See the [Provider Reference](/providers/overview) for the full list.
  </Step>
  <Step title="Define your schema">
    Describe the output shape using a `FormatModel` JSON schema — the same schema drives both the API call and TypeScript type inference.
  </Step>
  <Step title="Call generateObject()">
    Pass your provider, schema, messages, model name, and API key. Get back a fully typed JavaScript object.
  </Step>
</Steps>

<Note>
  Ollama is the only provider that doesn't require an API key — it runs locally on `localhost:11434`.
</Note>
