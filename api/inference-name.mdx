`InferenceName` is a string enum that identifies which LLM provider `generateObject()` and `generateText()` should route a request to. Every member maps to a specific HTTP base URL and a completion strategy — either native `response_format` JSON output or a `provide_answer` tool-calling approach. Passing the wrong enum value for your API key will result in an authentication error from the target provider.

## Import

```typescript
import { InferenceName } from 'json-inference';
```

## Completion Strategies

The library uses two distinct completion strategies depending on the provider:

**`response_format` providers** (OpenAI, Grok, Perplexity, Cohere, GLM-4) send your `FormatModel` schema as a native `response_format: { type: "json_schema" }` parameter. The model returns JSON directly in its content field. A single attempt is made.

**`tool-calling` providers** (Claude, DeepSeek, Mistral, HuggingFace, Ollama, Alibaba, Groq) wrap your schema inside a `provide_answer` tool definition and force the model to call it via `tool_choice`. The tool call arguments are extracted, repaired with `jsonrepair`, validated against your schema, and retried up to 5 times on failure before throwing.

<Note>
  `InferenceName.OllamaInference` is the only provider that does not require an
  `apiKey` argument. Ollama runs locally and listens on `localhost:11434` by
  default. All other providers require a valid API key.
</Note>

## Usage Example

<CodeGroup>
```typescript Basic usage
import { generateObject, InferenceName } from 'json-inference';

const schema = {
  type: "object",
  required: ["answer"],
  properties: {
    answer: { type: "string", description: "The answer" },
  },
} as const;

const messages = [{ role: "user" as const, content: "What year was TypeScript released?" }];

// Pick any provider by swapping the first argument
const fromOpenAI    = await generateObject(InferenceName.GPT5Inference,       { format: schema, messages }, "gpt-4o",                     process.env.OPENAI_API_KEY);
const fromClaude    = await generateObject(InferenceName.ClaudeInference,     { format: schema, messages }, "claude-3-5-sonnet-20241022",  process.env.CLAUDE_API_KEY);
const fromDeepseek  = await generateObject(InferenceName.DeepseekInference,   { format: schema, messages }, "deepseek-chat",               process.env.DEEPSEEK_API_KEY);
const fromMistral   = await generateObject(InferenceName.MistralInference,    { format: schema, messages }, "mistral-large-latest",        process.env.MISTRAL_API_KEY);
const fromGroq      = await generateObject(InferenceName.GroqInference,       { format: schema, messages }, "llama-3.3-70b-versatile",     process.env.GROQ_API_KEY);
const fromOllama    = await generateObject(InferenceName.OllamaInference,     { format: schema, messages }, "llama3.3:70b");
```
