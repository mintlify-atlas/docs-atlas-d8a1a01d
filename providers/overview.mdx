`json-inference` ships with built-in support for twelve LLM providers. Every provider is accessed through the same `generateObject()` function — you simply swap the `InferenceName` enum value to change providers. Under the hood, the library routes each call to either a native `response_format` path or a tool-calling path, depending on what the provider reliably supports.

## Output Strategies

`json-inference` uses two different strategies to guarantee structured JSON output, chosen automatically per provider.

<CardGroup cols={2}>
  <Card title="response_format" icon="brackets-curly">
    Used by providers with native JSON schema support: **OpenAI, Grok, Perplexity, Cohere, GLM-4**. The schema is sent directly as `response_format: { type: "json_schema", ... }`. A single API call is made and the content is parsed directly. Refusals are thrown as errors.
  </Card>
  <Card title="tool-calling" icon="wrench">
    Used by providers that lack reliable `response_format` support: **Claude, DeepSeek, Mistral, Hugging Face, Ollama, Alibaba, Groq**. The schema is wrapped as a `provide_answer` tool definition, `tool_choice` forces the model to call it, and the arguments are extracted, repaired with `jsonrepair`, and validated. Retries up to 3–5 times on failure.
  </Card>
</CardGroup>

## Local vs. Cloud Providers

<Note>
  **Ollama** (`OllamaInference`) is the only provider that runs entirely on your local machine. It connects to `localhost:11434` by default and requires no API key. All other providers are cloud-hosted and require an API key obtained from their respective developer consoles.
</Note>

## Installation

All three peer-dependency SDKs must be installed alongside `json-inference`:

```bash
npm install json-inference openai ollama groq-sdk
```

| Package | Covers |
|---|---|
| `openai` | OpenAI, Claude, DeepSeek, Mistral, Perplexity, Cohere, GLM-4 |
| `ollama` | Ollama |
| `groq-sdk` | Groq |
