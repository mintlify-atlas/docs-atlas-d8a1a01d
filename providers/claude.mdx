`json-inference` integrates with Anthropic Claude using `InferenceName.ClaudeInference`. Because Claude does not reliably honour `response_format`, the library uses a **tool-calling strategy**: your JSON schema is wrapped as a `provide_answer` tool, `tool_choice` forces the model to call it, and the arguments are extracted, repaired, and validated. The provider will retry this loop up to **5 times** (`MAX_ATTEMPTS = 5`) before throwing an error.

## Provider Details

| Property | Value |
|---|---|
| **InferenceName** | `InferenceName.ClaudeInference` |
| **Strategy** | tool-calling (`provide_answer` tool) |
| **Base URL** | `https://api.anthropic.com/v1/` |
| **Peer dependency** | `openai` (OpenAI-compatible SDK) |
| **Max retries** | 5 |

<Steps>

## How It Works

`ClaudeProvider` connects to `https://api.anthropic.com/v1/` using the OpenAI-compatible SDK. On each attempt it:

1. Builds a `provide_answer` tool definition from your `format` schema.
2. Prepends a system message that instructs the model to **always** use the tool.
3. Sends the request with `tool_choice` set to `provide_answer`.
4. Extracts `tool_calls[0].function.arguments`, repairs with `jsonrepair`, and validates all `required` fields.
5. On any failure (refusal, missing tool call, parse error, validation error) it appends a follow-up user message (once) and retries, up to 5 attempts.

<Tip>
  The system message is written in Russian by design — it matches the source implementation exactly and has proven effective at forcing tool usage across Claude model versions.
</Tip>

The injected system message reads:

```
ОБЯЗАТЕЛЬНО используй инструмент provide_answer для предоставления ответа.
НЕ отвечай обычным текстом.
ВСЕГДА вызывай инструмент provide_answer с правильными параметрами.
```

*(Translation: "You MUST use the provide_answer tool to provide the answer. Do NOT respond with plain text. ALWAYS call the provide_answer tool with the correct parameters.")*

## Code Example

<CodeGroup>
  ```typescript Trading Signal
  import { generateObject, InferenceName } from 'json-inference';

  const result = await generateObject(
    InferenceName.ClaudeInference,
    {
      format: {
        type: "object",
        required: ["position", "price", "stop_loss", "confirmed"],
        properties: {
          position:  { type: "string",  description: "long, short, or wait" },
          price:     { type: "number",  description: "Entry price in USD" },
          stop_loss: { type: "number",  description: "Stop-loss price in USD" },
          confirmed: { type: "boolean", description: "Signal confirmed by indicator" },
        },
      },
      messages: [
        {
          role: "user",
          content: "BTC is at $67,500 with RSI at 72 and MACD crossing down. What trade signal?",
        },
      ],
    },
    "claude-3-5-sonnet-20241022",
    process.env.ANTHROPIC_API_KEY,
  );

  // result.position  → string
  // result.price     → number
  // result.stop_loss → number
  // result.confirmed → boolean
  console.log(result.position, result.price);
  ```

  ```typescript Sentiment Classification
  import { generateObject, InferenceName } from 'json-inference';

  const result = await generateObject(
    InferenceName.ClaudeInference,
    {
      format: {
        type: "object",
        required: ["label", "score"],
        properties: {
          label: {
            type: "string",
            description: "positive, negative, or neutral",
            enum: ["positive", "negative", "neutral"],
          },
          score: { type: "number", description: "Confidence score 0-1" },
        },
      },
      messages: [
        { role: "user", content: "Classify: 'The delivery was late and the item was broken.'" },
      ],
    },
    "claude-3-haiku-20240307",
    process.env.ANTHROPIC_API_KEY,
  );

  console.log(result.label, result.score);
  ```
</CodeGroup>

## Retry Behaviour

<Warning>
  If Claude fails to call the `provide_answer` tool after **5 attempts**, `generateObject()` throws:
  `Error: Model failed to use tool after maximum attempts`
  
  This is uncommon with `claude-3-5-sonnet-20241022` but can occur with lighter models or very complex schemas.
</Warning>

Each retry appends a follow-up user message (sent only once across all retries) asking the model to use the tool. This is implemented with `singleshot` from `functools-kit` so the conversation history does not grow unbounded.
